## 🚀 GitHub Pages дээр байршуулах (Хост хийх заавар)

Энэ төсөл нь зөвхөн HTML, CSS, JavaScript-ээс бүрдсэн учир ямар ч Node.js/Backend сервер тохируулах шаардлагагүй, GitHub Pages дээр шууд ажиллана:

### 1-р алхам: GitHub дээр шинэ репозитор үүсгэх
1. [github.com](https://github.com) руу нэвтэрнэ.
2. Баруун дээд талын **+** товчийг дараад **New repository** сонгоно.
3. Нэр өгнө (жишээ нь: `kahoot-mgl`).
4. **Public** сонгоод **Create repository** дарна.

### 2-р алхам: Кодоо хуулах (Push хийх)
Та энэ фолдер (`d:\cote\gahai`) дотроо терминал нээгээд дараах командуудыг бичнэ:

```bash
git init
git add .
git commit -m "Initial Kahoot Mongolia commit"
git branch -M main
git remote add origin https://github.com/ТаныНэр/kahoot-mgl.git
git push -u origin main
```

*(Хэрэв та git ашигладаггүй бол GitHub сайт дээрээ "uploading an existing file" товчийг дараад эдгээр бүх файлуудыг чирч оруулаад Commit дарж болно).*

### 3-р алхам: GitHub Pages идэвхжүүлэх
1. Репозиторынхоо **Settings** цэс рүү орно.
2. Зүүн гар талын цэснээс **Pages** гэснийг сонгоно.
3. **Build and deployment** хэсэг дэх **Source**-ийг `Deploy from a branch` болгоно.
4. **Branch** дээр `main` (болон `/root` фолдер)-ийг сонгоод **Save** дарна.

### 4-р алхам: Тоглох!
1-2 минутын дараа таны сайт бэлэн болно:
👉 `https://таны-нэр.github.io/kahoot-mgl/`

## 🎮 Хэрхэн тоглох вэ?

1. **Хост (Багш / Зохион байгуулагч)**:
   - Компьютер эсвэл ТВ дэлгэц дээрээ сайтыг нээгээд **"Өрөө үүсгэх"** дарна.
   - Дэлгэц дээр 6 оронтой PIN болон QR код гарч ирнэ.
2. **Тоглогчид (Сурагчид / Найзууд)**:
   - Утаснаасаа QR кодыг уншуулах эсвэл сайт руу орж **"Тоглоомд орох"** дээр дараад PIN кодоо бичнэ.
   - Нэрээ бичиж, дуртай аватараа (🐼, 🦊, 🦁...) сонгоод **"Нэгдэх"** дарна.
3. **Тоглоом эхлэх**:
   - Хост **"ТОГЛООМ ЭХЛЭХ"** дарахад 10 асуулт дараалан гарч, тоглогчид утаснаасаа зөв өнгийг дарж оноо цуглуулна!
