🚀 GitHub Pages дээр байршуулах заавар

Энэ сайт нь ямар ч сервер код шаардахгүйгээр 100% GitHub Pages дээр үнэгүй ажиллана!

Алхам 1: GitHub дээр шинэ Repository үүсгэх

github.com руу ороод New repository дараад жишээ нь kahoot-mgl гэж нэр өгөөрэй (Public байх ёстой).

Алхам 2: Файлуудаа байршуулах

Терминал дээр дараах командуудыг ажиллуулна:

git init
git add .
git commit -m "Kahoot game ready"
git branch -M main
git remote add origin https://github.com/ТаныНэр/kahoot-mgl.git
git push -u origin main
Алхам 3: GitHub Pages идэвхжүүлэх

Repository-ийнхаа Settings ➔ Pages цэс рүү ороод Source хэсэгт Deploy from a branch, Branch-д main / root сонгоод Save дарна.

Алхам 4: Тоглоомоо эхлүүлэх!

1-2 минутын дараа таны сайт бэлэн болно:
https://таны-нэр.github.io/kahoot-mgl/ холбоосоор найзуудаа урин зэрэг тоглоорой! 🎉
